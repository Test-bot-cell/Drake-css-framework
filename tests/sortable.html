JavaScript Options

Option Value Default Description
group String The group
animation String, Boolean slide Animation mode (slide, fade, delayed-fade, false).
duration Number 150 Animation duration in milliseconds.
threshold Number 5 Mouse move threshold before dragging starts.
cls-item String drk-sortable-item The item class.
cls-placeholder String drk-sortable-placeholder The placeholder class.
cls-drag String drk-sortable-drag The ghost class.
cls-drag-state String drk-drag The dragging class added to the root element.
cls-base String drk-sortable The list's class.
cls-no-drag String drk-sortable-nodrag Prevent dragging on elements with this class.
cls-empty String drk-sortable-empty The empty list class.
cls-custom String The ghost's custom class.
handle String false The handle selector.
