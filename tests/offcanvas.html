JavaScript Options

Option Value Default Description
mode String slide Offcanvas open mode (slide, reveal, push, none).
flip Boolean false Flip Offcanvas to right side.
overlay Boolean false Show Offcanvas together with an overlay.
container Boolean false Define a target container via a selector to specify where the Offcanvas should be appended in the DOM.
esc-close Boolean true Close the Offcanvas when Esc key is pressed.
bg-close Boolean true Close the Offcanvas when background is clicked.
